# Skopio for JetBrains

Track your coding activity in JetBrains IDEs via categorized events.
The JetBrains plugin logs your coding sessions locally, and optionally sync them with the
Skopio desktop app for richer analytics.

## Features

- **Categorized Event Tracking** - detect and log activity types:
    - **_Coding_**
    - **_Debugging_**
    - **_Compiling_**
    - **_Writing Docs_**
    - **_Code Reviewing_**

- **Idle Time Awareness** - does not log when you are inactive or away from the keyboard.

## Usage

Once installed:

- The plugin automatically starts sending events to the main skopio desktop app whenever you:
    - Edit a file
    - Move your cursor
    - Swith between files.

- Activity is categorized by detected task type (e.g., Coding Debugging).
